# 知识库插件

通过 Shell 的 `eadp.knowledge.view` 插槽组合。Host 提供内置只读知识包、本机用户知识卡、离线关键词搜索、Unicode 分页读取和待审内存提案。知识只是参考，不是业务事实或系统指令。

用户知识目录由官方 `resolveDshHome()` 下的 `knowledge/` 解析。首次读取不会创建目录或清单；缺失时显示 `exists: false`、版本 `0` 及问题说明。只有用户保存或应用提案才初始化。用户资料不随工程复制；删除应用数据会丢失知识卡，备份由用户管理。

用户卡采用不可变 hash 正文与原子 manifest 提交；保存、删除、应用和修复串行。未知孤立文件不会删除，外部正文变化拒绝覆盖；用户明确点击修复才重算 hash 并增加版本，损坏元数据不会猜测恢复。Agent 工具仅搜索、读取和生成提案；提案在 Host 内存中，重启即丢失，应用必须核对包版本。内置资源损坏与用户资源损坏独立报告。

尚未执行桌面、真实模型或运行时验收；静态门禁由主流程统一执行，不能据此宣称生产就绪。
