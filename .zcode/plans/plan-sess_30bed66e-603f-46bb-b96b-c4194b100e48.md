# Studio 桌面外壳演进：统一设置弹窗、新建会话回原生界面、顶栏重做

## 已确认的决策（含技术依据）

1. **设置合并**：DSH 槽框架禁止渲染未声明子槽（`SlotOwnershipError`）、禁止重复声明（register 时抛 `slot is already declared`），原生节无法嵌进 Studio 自绘弹窗。采用反向路线：Studio 的节注册进原生 `settings.section` 槽，**原生设置弹窗成为唯一设置 modal**，删除自绘 StudioSettings。
2. **新建会话**：`ctx.uiWorkspace` 是公开跨插件服务，其 `startSession()` 即原生"新建会话"完整实现（复用/新建空白会话 + `selectPanel(null)` 切回原生对话面板），无需上游补丁。同时向 `sidebar.panellist` 槽注册 "EADP Studio" 面板行，作为原生界面里返回 Studio 的入口（今天用户进入 Studio 后回不去原生界面，这是前提缺口）。
3. **顶栏**：桌面模式把身份条 + 动作区合并进 40px caption 带，取消下方 46px 工具栏行（web 回退保留单行工具栏）；先重构为声明式条目模型（数据驱动渲染，后续加菜单项不改组件）。

## 改动清单

### A. 设置统一（原生壳为唯一 modal）

- `packages/studio-plugin/src/client/index.ts`：
  - 新增 `ctx.slots.inject('settings.section', …)` 注册四节：`studio-collab` 协同账号(order -9)、`studio-appearance` 外观(order 5)、`studio-connection` 协同连接(order 6)、`studio-about` 关于(order 200)。节组件经自己的 `inject` 拿 `call`（studio 命令）、`theme` face，自行拉取 `state`。
  - `openHostSettings` 更名为 `openSettings(section?)`（仍派发 `eadp:open-settings`，桥接补丁不动）。
- 新增 `src/client/settings/sections.tsx`（+ sections.module.css，迁移自 StudioSettings.module.css）：移植 Account/Appearance/Connection/About 四节为槽节组件；登录/登出成功后派发 `eadp:studio-state-changed`，StudioPanel 监听并立即 `call({action:'state'})`（避免等 10s 轮询）。
- 删除 `StudioSettings.tsx`、`StudioSettings.module.css`、`ModelsSection`（模型节由原生弹窗直接提供，不再跳转）；StudioPanel 移除 settingsOpen/settingsSection 状态，齿轮、欢迎页登录按钮、`LOGIN_REQUIRED` 处理全部改为 `openSettings('studio-collab')`。
- 原生节全部保留：账号(DeepSeek 平台)、通用、模型、插件、Agent 预设、子代理 + Studio 四节，同一弹窗左导航呈现。
- **新上游锚点补丁** `apps/desktop-distribution/build/studio-settings-sections-edits.mjs`：给 `ui-settings-general/src/client/SettingsRoot.tsx` 的 `navIcon()` 增加 studio 节 id → 现有 primitives 图标映射（协同账号→user、外观→palette/sun、协同连接→server、关于→info），未命中仍回退齿轮。注册进 `prepare-studio-plugin.mjs` 的 `UPSTREAM_EDITS`，并补 `tests/scripts/` 回归断言（锚点缺失即构建失败惯例）。

### B. 新建会话回原生界面 + 返回入口

- `client/index.ts`：inject 增加 `'uiWorkspace'`（补类型导入 `@deepseek-ai/dsh-client-ui-workspace/client`，构建期在 DSH workspace 内解析）；StudioFace 增加 `startSession(): void`（= `ctx.uiWorkspace.startSession()`）。
- `ctx.slots.inject('sidebar.panellist', …)` 注册 `{ id:'studio', label:'EADP Studio' }` + 图标组件（接收 `{size, active}` owner props）——原生侧栏出现 Studio 面板行，点击 `selectPanel('studio')` 返回。
- 任务级「与 AI 整理 / 恢复对话」不变（purpose 绑定的会话命令，与全局新建会话是两回事）。

### C. 顶栏重做（caption 合并 + 声明式条目）

- 新增 `src/client/topbar/items.tsx`：声明式条目模型 `{ kind:'button'|'menu'|'link', id, label, icon?, run, checked?, disabled?, visible? }`；内置条目：新建会话（primary）、本地原型链接（preview 存在时）、视图菜单（五阶段 + 主题三项）、设置、刷新。渲染器统一消费条目列表，后续功能追加条目只改声明不改组件。
- `StudioTopbar.tsx` 重构：桌面（`data-windows-titlebar`）模式把身份条与动作区一起渲染进 `.captionIdentity`（交互元素 `no-drag`、身份文本保持 `drag`、右侧 150px 窗口控制保留区不变），46px `.topbar` 行仅 web 回退渲染；折叠钮仍固定 caption 左 12px。
- CSS（`studio.module.css`）：caption 区新增 actions 簇样式；`.topbar` 标记为 web 回退专用。
