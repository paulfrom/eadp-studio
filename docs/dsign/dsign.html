REQ-202610-09 跨境保理池动态贴现与结算规约

责任人 li.yuchen @ PMO· 最后更新 刚刚· Docs-as-Code Spec v2.2

1. 业务目标与背景

本规约承载跨亚太区贸易保理池的动态贴现自动化清算。通过将核心企业的应付账款转让确权上链存证，实现 Tier-1 供应商在营业日内发起自主贴现，并由资金存管行按照实时浮动基准利率（SOFR / LPR + Spread）即时划拨结汇。

2. 核心业务流程时序

1.贴现发起与验真：供应商提报凭证，智能校验发票与跨境报关提单关联
2.保理池额度预占用：分布式锁锁定总信用额度，触发实时合规反洗钱黑名单过滤
3.实时汇率与点差锁定：通过路透 / 银行 API 获取 60 秒窗口锁定汇率，锁定动态贴现率公式
4.存管行划拨分账：银企直连发起多币种支付，自动扣除综合服务手续费并生成清算回单

3. 验收规则与契约判定

RULE_01动态贴现利率与额度扣除规约
GIVEN 贴现申请单已提报且供应商资信评级 ≥ AA，当前池可用额度充足
WHEN 触发保理结算中枢执行计息测算动作
THEN 自动套用动态浮动 LPR + 25BP 计息，并在核心信用账本中冻结对应保理额度
RULE_02多币种清算汇率异常阻断机制
GIVEN 涉及跨境跨币种支付流水，外汇报价源通道已接通
WHEN 瞬时外汇牌价波动幅度单日累计超过 0.05% 或数据心跳中断
THEN 立即挂起流水通道，触发人工双岗复核预警并向资金主管发送阻断通报
