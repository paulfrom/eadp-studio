# 原型开发验证样本与记录

状态：2026-10-27，以下样本随对应开发工作包执行，不另设前置阶段；当前不是运行结果。范围及业务决定以[交接文档](development-handoff.md)为准。不得擅自修改指定协同服务或真实数据；干净机安装在候选发行包阶段验证。

每次运行记录源码提交和工作区差异、固定 DSH commit、实际桌面／工具版本、运行环境、样本和命令、期望及实际、脱敏日志／截图／trace、失败及未验证项。工具锁文件是预期版本，实际版本须由运行时核对；未知写未知。局部检查不能代替当前交付版本的真实桌面闭环。

## PT05 内嵌预览

按[承载与浏览器验证](technology-and-browser-validation.md)的候选方案，在固定宿主记录创建、显示、缩放、焦点、遮挡、切换、关闭及重开。对受管静态产物验证正常运行，再分别尝试工作台桥接、Node、preload、跨端口与外站访问、弹窗及越界导航；记录实际阻断位置和监听端结果。检查尺寸变化、窄窗与设备画布，确认实例关闭不误伤其他实例。失败时返回承载设计，不通过全局放宽 CSP 或升级宿主掩盖。

## PT03 原生消息与恢复

在隔离测试现场记录一条明确发送的用户消息、原生会话 ID、messageOperationId、可观察的原生消息 ID／事件、落盘屏障及重启后对应关系；分别注入发送前中断、发送途中断、收到确认后退出、取消未 settled、flush 失败和强杀。实际支持哪些 ID、ack 和持久屏障以固定宿主证据为准。对无法证明发送或未发送的情况保留 unknown，不按相同正文推断或重新发送。正常关闭保存失败时核对输入仍在界面；强杀未落盘的最后输入不承诺恢复。避免记录凭据与不必要的模型内容。

## PT02 Git 候选树一致性

仅在隔离的本地样本库比较桌面锁定 Windows Git 与拟定同上游版本 Linux Git，记录各自可执行文件版本、摘要、平台、命令、受控环境、策略及配置。分别输出真实 base／head／source／candidate 的 commit SHA、原型子树 tree ID，以及合成提交 SHA 与计算结果 tree ID；合成提交只用于计算，不能证明真实父关系。当前 [WorkspaceGit.merge](../../../packages/studio-plugin/src/host/adapters/workspace/git.ts) 调用工作树 `git merge`；它不是拟议子树 `merge-tree` 对照已通过的证据。

| 样本 | 应核对的结果 |
| --- | --- |
| 同一祖先，双方修改不同原型文件 | 两平台和服务端重建算法的原型结果树一致，真实 candidate 的父顺序与非原型树另行核对。 |
| 一方修改原型，另一方只推进材料头 | 材料来自真实 expectedHead，原型树仅含允许的两侧改动；材料推进不能使旧原型基线 SHA 改写。 |
| 原型文件重命名加对侧编辑、删除与对侧编辑 | 记录重命名策略、冲突与退出状态；两端结果一致才可选择支持，不一致回设计。 |
| 同行冲突及二进制冲突 | 不能报告 clean；保留冲突现场和原因，修复后新成果需用户确认。 |
| 多个共同祖先、无共同祖先或对象缺失 | 核对实际历史与选定策略；未能证明合成树等价时拒绝，不由请求自报祖先。 |
| 混入第三方未接受内容、改非原型树、伪造父顺序／候选树 | 验证器拒绝；不能只比较客户端声明或只比较最终文件名。 |
| 超限、超时、中断及残留临时对象 | 记录对象数、字节、资源上限和终止、清理结果；失败拒绝，不能退回信任 Host。 |

这些是开发期间的验证断言，并非已建立或运行的样本。资源阈值和具体 Git 配置须在实际固定工具验证后定稿；不能把本机当前 Git 版本当作发行锁版本。

## PT04 编辑与并发

在隔离工程核对固定 CodeMirror 组合的挂载与销毁、中文输入、只读和差异展示；模拟人工缓冲、Agent 与外部修改同一文件，验证同路径串行、锁内重验 hash、冲突保留双方以及切换／退出恢复。检查受控目录、符号链接越界、二进制、凭据过滤和结果上限；在隔离工程执行，不修改用户业务工程。

## PT05B 浏览器与发行

执行[浏览器实现验证](technology-and-browser-validation.md)，分开记录 Chromium 业务用例、实际 sink 网络围栏、Electron 保护和真实桌面交互。核对 Playwright 与浏览器 revision 配对、专属实例／会话／origin 绑定、取消恢复及截图进入真实模型。候选安装包完成后，在未预装浏览器的干净环境验证离线安装和首次启动；记录安装包字节数及 SHA-256。未执行的发行关口保持未验收。
