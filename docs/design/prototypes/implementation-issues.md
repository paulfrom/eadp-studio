# 原型开发工程问题清单

本清单集中记录实现过程中发现的工程逻辑问题和尚未完成的衔接，供后续继续开发使用；它不是开发阶段的门禁，也不表示这些问题已通过运行验证。用户要求本轮不执行构建、测试或验收。

| 编号 | 当前实现及剩余证据缺口 | 后续处理 |
| --- | --- | --- |
| I01 | 指令按 operationId 持久化并区分 delivered／admitted／unknown；队列重排、切换前暂停、暂停恢复、原消息核对、原生输入 pre-step 统一准入和关闭前收敛／flush 已接入。未收敛时保留原选择、现场和操作，未确定投递结果时不重发。固定宿主的实际消息耐久语义、取消、工具收敛和重启行为尚无运行证据。 | 在当前固定宿主核对消息、取消、flush、关闭阻止和重启恢复；既有缺少操作身份的现场不能自动判定结果。 |
| I02 | 事项工程提供磁盘差异；人工保存和原生 AI write／edit 共用路径锁及锁内授权核对。固定基线已有独立只读文件现场、检查和预览，崩溃遗留快照仅在本进程登记并验证后清理。外部程序及父目录替换不受锁完全控制，实际行为未运行核对。 | 核对锁、固定快照和异常退出清理；不能由文件查询推断未接入的工程来源。 |
| I03 | 编辑缓冲按账号、事项和文件持久保存并保留原始 hash；CodeMirror 编辑／差异、磁盘三方对照、手动选择保存依据及受控 AI 合并到缓冲已接入，退出前区分已持久缓冲与未保存输入。依赖版本和许可清单已固定并接入装配核对；实际交互、异常恢复和发行内容未运行核对。 | 核对中文输入、合并、缓冲恢复、关闭行为和最终许可载荷。 |
| I04 | Host 已接入固定 source、审阅、作者确认、source 上传、隔离子树干净合并、合并后独立快照重检、冲突写回及重新确认；accepted 后按持久步骤完成投影、复用回写、预览关闭、资源释放、主检出同步和临时目录清理。后台已接入模板权威策略和独立 Git 子树重算，供应链事实见[记录](../../../apps/collaboration-api/git-verifier-supply-chain.md)。源码清单签名、编译依赖、最终镜像／二进制摘要、容器总资源隔离和平台一致性仍未核对。 | 完善并核实供应链锁、资源隔离和崩溃清理；不能将客户端声明当作后台验证或业务用例通过。 |
| I05 | 首次及后续指令已接入无工具模型识别、目录／原文片段核对和原操作持久化；识别新需求后先扩领再更新 scope，原生输入统一经过准入。自由指令消歧和实际代码范围推导仍依赖模型，尚无固定宿主运行证据。 | 核对明确指令到需求及代码范围的推导；不能以未识别范围伪装授权。 |
| I06 | 文件保存记录操作身份和原始／目标 hash，并可按磁盘内容恢复中断保存；人工和原生 AI 写入共用路径锁，外部程序不受该锁约束。 | 在后续运行中核对并发、授权变化和未知结果恢复。 |
| I07 | prepared 查询、原提交阶段投影、取消与 abort 竞争、accepted 独立收尾及复用成功回写已接入；接受或取消前会先 fetch 再核对真实 Git 头。晚到 push 形成分叉时仍需要受保护的管理员 correction／reconcile，普通取消不能冒充已完成 Git 收敛。 | 保留原现场和已接受事实，为 reconcile-required 提供受保护的后续核对；不盲目覆盖远端分叉。 |
| I08 | 隔离原生视图、Host 实例登记／选择和工作台画布已接入，模态遮挡时隐藏画布；预览独立执行必要构建和静态保护检查，基线与事项使用不同身份。检查步骤、退出码和指纹已持久记录，进程完整日志、证据复用及重启后失效核对尚未接齐，固定宿主的 DPI、焦点和生命周期未验证。 | 补检查日志和证据失效管理，在真实桌面核对遮挡、隔离、销毁与恢复。 |
| I09 | 工作台已投影原生文本、操作身份、附件元数据和工具调用／结果；指令附件经 DSH 权威存储取得引用后按原 operationId 发送。受限浏览器已接入原生工具、双分发物清单、进程树生命周期、截图／trace 附件及预览失效关闭。[发行记录](../../../apps/desktop-distribution/build/studio-browser-runtime.md)保留两个 Chromium 归档尚未取得的真实 SHA 和许可审核缺口。 | 取得并审核真实归档后完成发行装配；分别验证 Electron 保护、Chromium 业务用例及真实桌面闭环，不能相互替代。 |
| I10 | source 审阅、冲突修复重确认、接受后收尾、交接固定来源、原型复用登记／成功回写和发布固定 commit 已贯通。[数据模型](data-model.md)记录当前 SQL 和关系；受影响测试源码继续同步，但本轮未执行，跨端契约不能仅凭静态代码判定可运行。 | 保持消费者与有效测试同步，后续用真实事务和桌面闭环验证。 |
| I11 | 文件服务按受限内容及集合生成观察标识，超出数量、字节或时间预算时停止分页并标记不完整；扫描中变化要求重新读取。单文件超过 16 MiB 或总量超过 64 MiB 时无法取得完整观察，搜索跳过超过 1 MiB 的文件并提示。实际分页一致性及性能未运行核对。 | 核对扫描中改写、分页一致性和大文件性能，超限结果不得冒充完整工程。 |
| I12 | 文件服务提供受限行范围、扫描预算、末端不跟随链接及文件描述符身份复核；完整范围可继续下一页，仅达到内容／扫描上限时标记截断。超长单行、16 MiB 以后位置和父目录解析／打开竞争仍受限。 | 后续核对范围读取、符号链接竞争和大文件边界；平台无法消除的父目录竞争须明确保留。 |
| I13 | 本人登记草稿及已确认需求正文通过只读工具访问，实际行范围和 hash 在正文进入工具结果前持久化；材料更新只标记提醒，不重绑工程。指令附件已接入，路径竞争和模型实际行为仍未运行核对。 | 核对自由指令消歧、附件、读取证据和权限竞态；异常或更新不得自动改代码。 |
| I14 | 交接任务记录基线和消息操作身份，生成及固定候选时核对草稿中的基线 ID／SHA；投递未知时查询原消息且不重发。原生消息来源与日志耐久语义尚无运行证据，既有缺少消息身份的现场不能自动判定投递结果。 | 核对原生消息协议和交接确认／重试闭环，保留已有草稿和无法判断的原操作。 |
| I15 | [事项模块](../../../apps/collaboration-api/src/modules/prototypes.ts)在 prepared 时限制事项变更，取消／释放同事务终止原集成并撤销占用；[服务编排](../../../apps/collaboration-api/src/service.ts)记录 abort 后的 pending recovery 并支持管理员 reconciliation。Host 保留 gitRecovery 并在决策前 fetch，但普通用户的当次 Git 观察不是晚到 push 的最终结论。 | 结合原集成和远端事实完成受保护的晚到恢复；未知或分叉不得宣称 clear。 |

本轮真实桌面、模型、协同服务、Git 与持久化闭环均未执行，状态为未验收；后续不得以本清单或静态代码代替运行证据。
