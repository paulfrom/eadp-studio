# 原型开发工程问题清单

本清单集中记录实现过程中发现的工程逻辑问题和尚未完成的衔接，供后续继续开发使用；它不是开发阶段的门禁，也不表示这些问题已通过运行验证。用户要求本轮不执行构建、测试或验收。

| 编号 | 问题及现有证据 | 后续处理 |
| --- | --- | --- |
| I01 | 原型指令已携带操作 ID 并尝试从原生日志识别，但尚未取得固定宿主对消息来源持久化、投递确认和事件重放的运行证据；`cancel` 只发出请求，没有等待在途工具收敛的证明。 | 核对实际会话协议并补齐消息结果查询、取消收敛及关闭 flush；不能确定投递结果时保留原操作，不自动重发。 |
| I02 | 事项工程已按起始提交与当前磁盘内容提供差异；人工保存和 AI 文件工具尚未共用写锁，已接受基线的只读工程现场也尚未接入。 | 接入统一路径写入协调及只读基线现场，文件查询不能假称代表尚未接入的工程来源。 |
| I03 | 编辑缓冲已按账号、事项和文件持久保存，恢复时保留原始 hash；成熟编辑器和磁盘冲突合并界面尚未接入，异常退出后的恢复也尚未经过运行检查。 | 接入既定编辑器与差异处理，并在后续运行中核对缓冲保存、恢复与冲突行为。 |
| I04 | 后台已建立原型事项、接受、基线及复用接口，但 Host 尚未构造和提交新原型精确候选；服务端候选树独立重算与模板策略权威来源尚未接入。 | 完成候选固定、上传、确认、合并及恢复，并实现服务端候选验证和模板策略来源，不能将客户端声明当作后台验证。 |
| I05 | 原生对话输入尚未统一经过原型事项的需求识别、扩领和 scope 更新；指令到需求身份及代码范围的推导需要明确实现。 | 将首次和后续实现轮次接入同一编排，保留原指令及操作身份；不能以未经识别的范围伪装授权或让原生输入绕过协同占用。 |
| I06 | 文件保存已记录操作身份和原始／目标 hash，并可根据磁盘内容恢复中断的保存；它仍未与 AI 文件工具写入共用同一把路径锁。 | 统一人工和模型写入的串行化，并在后续运行中核对并发和未知结果恢复。 |
| I07 | 两类集成已接入项目级 prepared 查询，新基线交接和发布入口已切换；事项取消与集成 abort、结果未知和接受后的本机收尾仍未贯通。 | 完成原操作核对、取消与 abort 竞争处理，以及后台接受后的独立收尾。 |
| I08 | 目前工作台可显示受管预览的外开链接，尚无固定宿主内嵌预览承载；工程检查缺少持久结果与日志投影。 | 接入隔离的内嵌承载及实例生命周期，关联当前工程和产物；持久化并展示检查步骤与真实结果。 |
| I09 | 工作台已读取原生日志中的文本消息，完整原生对话投影、附件及工具事件尚未接入；受管浏览器、Chromium 随包运行时和业务用例证据尚未接入。 | 接入完整原生对话投影与受控输入，按既定运行时路线接入浏览器与附件。 |
| I10 | 当前原型的正式候选尚未接通桌面确认与后台接受，数据结构、SQL 对应的模型说明及下游契约也尚需整体核对。 | 完成确认摘要、候选 source／candidate、集成提交和接受后收尾，同时同步 schema-model、ERD 和受影响消费者。 |
| I11 | 目录和差异分页的工程观察标识目前使用文件名、大小及修改时间；同大小且时间戳不变的外部改写可能不会改变该标识。 | 改为受限文件内容与文件集合的可靠指纹，并处理扫描期间变化和大文件截断；后续再核对分页一致性。 |
| I12 | 文件服务尚未提供大文件行范围读取和扫描时间预算，路径解析与打开之间也需要进一步处理符号链接替换竞争。 | 补齐受限范围读取、扫描时间和分页边界，并在同一文件描述符上核对路径与内容。 |
| I13 | 原型会话尚未接入本人已登记需求草稿的受控读取与实际读取证据；也尚未从自由形式指令可靠识别开发需求。 | 在项目及账号权限范围内接入材料读取，记录实际读取状态与 hash，并补齐指令的需求身份识别。 |
| I14 | 新交接草稿会记录基线 ID 和提交 SHA，后台在收到该引用时核对两者；现有交接编辑与重复请求仍需保证该来源贯穿最终确认及恢复。 | 将来源身份贯穿交接任务、材料编辑、确认和重试，保留已有草稿并核对同一基线。 |
| I15 | [事项模块](../../../apps/collaboration-api/src/modules/prototypes.ts)的扩领、参考和 scope 更新尚未核对该事项是否已有 prepared 集成；取消／管理员释放直接结束 claims，[服务编排](../../../apps/collaboration-api/src/service.ts)返回 Git 结果未知。已有项目级 prepared 查询不等于这些竞争路径已经闭合。 | 结合原集成操作和远端事实，衔接 prepared 期间的事项变更、取消／释放、abort 及晚到 push 的恢复；保留原现场和已接受事实。 |

本轮真实桌面、模型、协同服务、Git 与持久化闭环均未执行，状态为未验收；后续不得以本清单或静态代码代替运行证据。
