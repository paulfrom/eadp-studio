# 需求文档编辑

2026-11-10。实现说明与桌面验收入口；当前未完成本轮真实桌面验收。

## 页面与编辑

- 需求编辑从左到右依次为目录、文件编辑区、原生 AI 会话；沿用原生会话完整内容与输入区，会话切换及新建入口保留。正文在编辑区域居中，材料树可通过专注模式收起；参考与依据默认折叠在正文下方。辅助组件保持挂载，避免开关面板丢失状态。
- 需求与知识共用 `packages/eadp-shell/src/client/document-editor/` 的 Lexical 编辑核心；原知识编辑器目录已删除，没有两套富文本实现。
- 默认直接编辑排版结果，提供源码切换、章节大纲、查找、保存。包含富文本节点未覆盖的结构时明确使用源码编辑，保留正文。
- 源码与排版模式均按当前文档的 buffer 身份保留本次运行内的选择、撤销历史和滚动。外部全文替换会重新载入，不能用编辑撤销冒充历史版本恢复。
- 需求暂无图片资源导入/读取链路，不展示插入图片入口。本地图片引用保留并提示显示限制；此次不宣称完成本地图片展示。

## 保存、冲突与草稿

- 保留 800ms 输入防抖、中文组字期间暂停写入、失焦保存及 Ctrl/Cmd+S。只有实际文件写入确认后才显示已保存。
- 保存失败、文件外部变更、文件已删除、检查文件状态失败分别处理；草稿暂存错误不冒充正文保存失败。
- 外部修改与当前输入提供全文对照。明确提供载入文件、以我的内容覆盖；载入替换或放弃输入前说明会丢失什么。覆盖仍对观察到的文件版本执行条件写入。
- 未提交输入经 Host 串行、同目录临时文件原子改名保存至项目 `.eadp/drafts/<路径摘要>.json`；文件内容含原路径、正文及基准版本。不得将该目录当作可重建缓存清理。
- 重启打开仍存在的同路径文档时，若有不同的未提交内容，先比较再恢复或放弃。恢复沿用原基准版本，不立即覆盖文件；保留的旧版本会在条件保存或外部检查时触发冲突处理。
- 暂不选择恢复时允许浏览其他文件，暂存内容保持。明确放弃已删除文件的输入时清理对应暂存记录。
- 草稿读取失败时保留记录，停止覆盖该记录，正文仍可保存。原文件被删除后，当前版本没有独立的孤立草稿列表；不要手工清理对应记录，可恢复同路径文件后再进入比较。

## AI 审阅

- 新提案仅更新数量，不抢正文焦点，不自动应用。
- 从待审入口打开独立宽幅审阅窗口，默认显示差异；按当前文档查看，也可切换全部以处理新文件提案。
- 展示目标路径、摘要、关联依据的来源与采用说明；提供完整候选文本及“应用并保存”“丢弃修改”。版本过期拒绝覆盖，要求重新生成。
- 不增加逐段接受、审批状态或业务确认门禁。固定依据保存规则沿用已有知识契约。

## 用户桌面验收清单

使用当前构建启动桌面（`pnpm dev:desktop`），不要沿用旧进程作为本轮结果。DSH 固定版本由 `apps/desktop-distribution/release.lock.json` 决定，本轮未升级宿主。

| 操作 | 预期 |
| --- | --- |
| 长段中文组字、撤销重做、标题/列表/表格输入 | 无截字、焦点跳动或未完成组字写入；保存后重开一致 |
| 排版与源码互切，切到另一文件再返回 | 正文一致；同文件独立撤销和位置恢复，不跨文件撤销 |
| HTML、脚注、公式等特殊结构文档 | 明确进入源码，打开但不编辑不会规范化并写回正文 |
| 文档内多次查找及大纲跳转 | 能定位正文；Enter/Shift+Enter 前后查找，Esc 返回编辑 |
| 输入后自动保存、Ctrl+S、切换文档/项目 | 保存状态与文件一致，迟到的请求不覆盖后续输入 |
| 外部修改文件、删除文件 | 不覆盖输入；可以对照、载入、覆盖或重建；覆盖前版本再次变化仍被拒绝 |
| 人为制造写入失败后恢复权限并重试 | 输入保留，可继续保存；检查失败与保存失败提示分离 |
| 存在未提交输入时中断桌面并重启 | 打开同路径文档显示比较；恢复/放弃符合选择，外部新版本不被静默覆盖 |
| 真实模型生成提案，再人工改正文 | 提案不抢焦点；审阅可见差异和目标，过期提案不能覆盖人工修改 |
| 提案采用知识并应用保存 | 本次参考与需求依据含义保持，保存后可回读依据 |
| 收起目录、打开参考、窄窗口和长文档 | 正文可用，辅助区域可滚动，退出专注不丢状态 |
