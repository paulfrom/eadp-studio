# 移除 legacy 项目只读兼容

状态：Accepted（2026-10-28），Supersedes ADR-0006、ADR-0007。

## 背景

ADR-0006 曾为早于模板目录与当前契约存在的项目保留只读兼容，ADR-0007 曾沿用同一策略允许三目录项目清单被读取。产品仍处于开发阶段、尚未开展业务人员试用，不存在必须保持可读的真实 legacy 项目数据（用户于 2026-10-28 确认）。保留两套契约读取分支与只读材料界面，使每个读写入口都要额外维护 legacy 判断，与项目规则 0「不保留向后兼容」冲突。

## 决策

删除 ADR-0006/0007 建立的全部兼容路径：三目录清单读取、legacy 材料投影与只读界面、legacy 错误码集合与相关分支、以及面向旧契约的模板缺省处理。项目清单与材料契约只保留当前版本；旧契约或三目录项目在打开、导入、初始化时明确报错拒绝，不迁移、不回填、不降级读取。

错误文案落在具体错误码处：项目清单不符合当前契约时报「项目契约版本过旧，不受支持」，已接受材料不符合当前契约时由后台以 `项目契约版本过旧，不受支持：<原始错误>` 拒绝。

## 后果

- 正：读写路径只剩一套契约，legacy 判断与只读界面消失；错误信息更直接。
- 负：旧契约项目不可再读取。由于尚未有真实业务项目，这一后果可接受。
- 替代方案（被否决）：保留只读兼容并定退役条件（在无真实数据时保留无收益）；提供一次性迁移工具（规则 0 禁止 migration；且无数据需要迁移）。
