# 场景阻断修复采用单次用户授权与 Host 自动确认

状态：已确认（2026-10-20），作为阶段一设计实施依据；不表示功能已实现或通过验收。

普通场景整理在用户采纳改动、阅读固定版本后确认；确认受阻时，具备权限且持有有效设计占用的用户可显式启动“AI 修复并确认”，授权本次修复任务依据已有资料直接修正结构、引用及可确定的内容，并由可信 Host 重新校验和提交确认，无须逐次采纳。缺少业务答案时暂停；用户提交“补充并继续修复确认”后续接同一任务，重读文件并重新校验版本、权限及占用，普通聊天回复不自动恢复。暂停及补答不重置轮次，同一任务累计最多 3 轮。

缺少可读取的依据、相同阻断无改善、发生并发编辑、额度耗尽、用户取消或任务完成均终止本次授权，保留现场并说明原因；不能编造业务答案。暂停期间若文件已被修改，按并发变更终止，不能沿旧授权覆盖新内容。详见[场景设计](../design/scenarios/01-scenarios.md)。

Host 将本次用户动作、起始版本、修复记录与最终版本对应，只有最终版本通过完整门禁且被协同后台接受后才显示已确认；后台接受结果未知时先查询核对。该选择减少已授权修复中的重复点击，同时保留普通采纳流程、业务决策边界及正式状态的可信来源。
