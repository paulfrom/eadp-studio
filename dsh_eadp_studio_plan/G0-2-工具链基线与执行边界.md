## 随包工具链与发行依赖门槛

本产品在 Linux 开发，在 Windows 原生打包、签名并执行干净机安装验收。开发机的 Node/pnpm/Git 仅用于构建与检查，不能成为用户使用桌面工作台的前置条件。用户无需另装 DSH、插件、系统 Node/pnpm/Git 或手工配置模板运行时。

固定官方 DSH 基线后，优先沿用经实测可用的宿主随包 Node/pnpm 等能力；Git 和实际模板运行时必须纳入发行依赖清单，能够沿用宿主随包能力的直接复用，缺少的在本产品发行中内置。每项记录版本、来源、许可、Windows 架构、校验值、安装路径和专用调用边界，连同宿主完整 production 依赖树随统一产品版本交付。不依赖用户 PATH，不在定位失败后切换系统工具，不保留过时工具兼容或 fallback。

验收须包含：

- Windows 干净机未安装 DSH、系统 Node/pnpm/Git 或模板运行时；安装本产品后可完成 clone、worktree、读固定 blob、push 与条件更新，模板冻结安装、检查、预览与静态构建可执行。
- 所有工具由发行清单所绑定的实际路径启动；验证工具版本、权限、含中文/空格路径、stdio、ready、取消和所属进程树清理，隔离开发机 PATH 带来的假通过。
- 模板仍按自身 `AGENT.md`、运行时和命令契约执行，不因桌面工程采用 pnpm 强制模板改栈。依赖源、企业代理/CA 与授权仍需实际验证；随包运行时不等于模板依赖全部离线可用。
- 通过统一产品渠道整套更新后复验宿主、内置插件、模板和运行时版本配套；不得由上游 DSH 更新替换该组合。升级保留用户业务资产与恢复信息，不释放后端在途持久占用；卸载不清理用户业务资产。
- 对所有真实 Agent 文件/shell 入口、安装/构建脚本及生成代码执行完成负向验证。内置运行时不自动证明执行隔离，普通 Agent 仍不得越权取用发布凭证或绕过专用执行边界。

本节是设计与验收约束，未生成安装包或运行时清单，未完成 Windows 实测。成熟模式见 [DSH desktop README](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md)；目标固定基线须独立验证，不复刻上游过时兼容路径。详细工具链与证据要求见 [07-开发与测试环境.md](07-开发与测试环境.md)。
