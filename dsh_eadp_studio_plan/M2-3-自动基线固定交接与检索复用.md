## 实现规格（原文节选，小节编号保留）

### 3.3 确认后自动合并、AI 辅助评审与成果追溯（节选）

单需求基线记录实际完成的需求版本、前置完成依据、集成成果及确认清单，可独立交接；项目批次清单只聚合已接受的固定成果。旧基线和来源保持不可变，作者直接确认与 AI 辅助评审后作者确认均可沉淀；只记录最终作者确认方式、固定引用及必要处置依据，AI 报告与过程留本地，不上传评审全文。Git 历史供资料追溯和显式复用，不提供历史站点或本地历史预览切换；远程展示按 3.5 更新唯一当前站点。

场景和需求材料经必需检查、固定正文推送 Git 且后端接受阶段确认即可独立沉淀，同时自动取得复用资格，无二次资格按钮或审批；不等待原型完成，也不因此形成原型基线。确认与资格分别记录但同时受理，重复确认事件不得恢复后续已停用资格。可复用资格须结合后端状态和 Git 固定材料核验；新增材料按业务领域分类，分类和明确状态随对应版本记录，客户端展示资格和原因，不能自行授予资格。新草稿不可复用，编辑新草稿不暂停旧固定版本已有资格；显式停用经后端接受后生效并阻止新的采用，受理前不能显示已生效。所有具有该资产编辑权限的成员均可停用/恢复，由后端按既有可信身份与该资产编辑权限受理并记录操作者、原因和时间，不以 Git 凭据代替授权；恢复不重做确认或基线。历史固定版本及已复制且独立维护的目标保留来源，不自动撤销。所有具有项目编辑权限的成员均可维护项目分类词表，新增场景/需求选择已有项目业务分类；编辑既有分类保留固定材料历史分类及 ID，不改写历史正文。实际词表值与实现编码作为 G0 输入/验证。

原型菜单确认某一个需求后，在该任务完整相关代码和文档集成成功且后端接受完成时自动固定基线；阶段场景/需求 MD 确认不提前形成原型基线。基线菜单用于查看，不再要求第二次人工审批。Host 后台任务以不可变基线为输入生成可交付清单，固定需求/场景资料、代码 SHA、前置与检查依据、已知限制及交接入口；生成结果存 Git 并引用来源基线，不移动来源基线，也不让清单引用自身的尚未生成哈希。后台生成不表示协同后端接收正文或执行 Agent。

清单展示生成中、可读取或失败待重试；生成失败独立重试，不撤销已完成需求、不重做集成和确认。确认事件幂等绑定同一基线和生成操作，防止重复清单；尚未生成成功不能展示“可交付清单已就绪”。验收覆盖重启恢复、失败重试、来源不可变和其他需求未完成草稿排除。

首期复用由作者显式选择完整场景包或完整需求包的固定 Git 版本，核验可复用资格及来源 Git 读取授权，记录目标场景/需求、来源和采用范围，在目标当前任务中调整并重验；不做规则、字段或代码片段级提取复用，不继承来源确认或完成状态。浏览或选中不算采用，以后端是否接受采用记录为界：停用生效时尚未接受的采用阻止，已接受的采用保留固定来源继续。采用受理不算复用成功；目标通过自身检查、确认并由后端接受后，登记目标最终固定版本及来源，失败或取消不计成功。采用后原型任务仍在目标当前 worktree 执行；来源旧版本不等于前置新范围已完成。外部人工编辑与 Agent 写入交错时重读固定来源并检测冲突，本地单写入锁不能假设锁住所有编辑器。

验收覆盖材料确认后原型未完成的独立沉淀与完整包复用、未完成原型代码拒绝进入基线、分类/状态及资格原因一致性、过期状态或本地篡改不能绕过后端资格，记录来源与调整后的目标检查结果。必要动作验收包括材料确认受理同时自动授资格且无二次操作、重复确认不恢复后续停用、具有该资产编辑权限的成员可停用/恢复且身份/权限与操作者/原因/时间可核验、恢复不重做确认或基线、仅有 Git 凭据不能授权、草稿拒绝采用、编辑新草稿不暂停旧固定版本资格、停用受理前不显示已生效且后端接受后阻止新采用、历史固定版本及已复制独立目标保留来源且不自动撤销；浏览/选中不算采用，停用时后端未接受的采用阻止、已接受的保留固定来源继续，采用受理不能绕过 Git 读取授权；采用受理不计成功，目标自身检查/确认被后端接受后登记最终固定版本及来源才计成功，失败取消不计成功；项目编辑成员维护词表、新增选择已有分类、编辑既有分类保留固定材料历史分类及 ID，不改历史正文。实际词表值与编码通过 G0 验证，不以检索命中或复制成功宣称复用完成。

## 关联架构契约

材料准入沿用原有确认检查：核心业务规则和验收条件必须明确，缺失时留草稿且不授资格；其他待澄清可以保留，但须展示限制与不适用范围，不由 AI 编造补齐，不增二次审批。正式确认材料、Git 可达固定引用、固定版本、来源记录及关联后端元数据/受理事件/来源证据长期保留，停用不删除；临时构建、缓存及任务现场单独清理，未提交、未推送成果和在途唯一现场须保护。验收覆盖核心缺失拒绝确认、非核心待澄清如实展示、停用后历史仍可读及证据仍可追溯、清理保留正式引用与证据并保护未完成现场，不建设备份平台。
