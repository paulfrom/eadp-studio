## 关联架构契约

两条路径验收：作者直接确认或经 AI 辅助评审后自行确认，均走同一可信确认与自动集成，不要求另一成员审批。AI 基于固定候选、需求版本及输入依据提供问题与建议，不能自授确认、资格或业务完成，不替代工程检查与后端门禁。候选或输入变化后重检、更新评审依据并重新确认，旧报告不能套用。最终作者确认方式、固定引用及必要作者处置依据按既有 Git/后端边界留证；AI 报告、对话及工具过程保留本地，不上传评审全文。

补充验收：一场景一 MD；自然语言/按钮两种入口绑定相同文件版本，修改后旧确认不覆盖新内容；场景确认后默认只创建一组本地需求候选并显示标题，失败可重试，候选不算确认、不提前占用。选中需求后完善并确认 MD，原型反馈与其冲突时走显式反向修订/重确认闭环。原型最终确认明确一个需求，仅集成本任务相关完整代码和文档；自动基线及 Host 后台可交付清单可追溯，清单失败独立重试，无二次基线审批、无其他需求未完成草稿混入。

资产验收分别覆盖材料与原型：原型未完成时，已通过必需检查并由 Git/后端阶段确认的场景或需求材料仍可独立沉淀；未完成原型代码不能进入原型基线。新增场景/需求按业务领域分类并明确记录状态，检索、成果视图与采用入口显示可复用资格和原因。验证完整场景包或需求包采用后记录固定来源、调整并重新检查确认，不能继承来源完成状态；验证 Git 材料、后端记录与客户端显示一致，篡改本地资格、使用过期状态或仅有 Git 提交均不能绕过后端核验。必要动作验收包括草稿拒绝采用、编辑新草稿不暂停旧固定版本资格、停用受理前不显示已生效且后端接受后阻止新采用、历史固定版本及已复制独立目标保留来源且不自动撤销。补充验证材料确认受理同时自动授资格且无二次操作，确认与资格分别记录、重复确认不恢复后续停用；所有具有该资产编辑权限的成员可停用/恢复，后端核验既有可信身份及该资产编辑权限，记录操作者、原因和时间，不以 Git 凭据代替授权；恢复不重做确认或基线。验证浏览/选中不算采用，停用时后端未接受的采用阻止、已接受的保留固定来源继续，采用受理不绕过 Git 读取授权；采用受理不计成功，目标自身检查/确认被后端接受后登记最终固定版本及来源才计成功，失败取消不计成功；所有项目编辑成员可维护词表、新增场景/需求选择已有项目分类、既有分类修改保留固定材料历史分类及 ID，不改历史正文。实际词表值与实现编码作为 G0 输入/验证，不预设状态枚举或额外审批。
