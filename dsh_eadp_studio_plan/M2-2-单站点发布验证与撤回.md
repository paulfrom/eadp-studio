## 实现规格（原文节选，小节编号保留）

### 3.5 单一当前站点的发布与验证

项目远程始终只有一个当前演示站点。作者在原型菜单点击“部署到远端”时，Host 读取项目当前已确认基线 ID、其固定代码 SHA 及后端完成依据；不提供发布历史版本、切换旧站点或选择任意任务分支的入口。后端不可达、基线/认可结果未知，或稳定分支存在尚未确认的集成时阻断发布。部署来源为当前已确认基线中的整个项目原型工程，包含已完成需求；本人尚未完成的 worktree 改动不能发布。阶段 MD 确认可推进认可集成头，但不会生成原型基线，不能以裸认可头替代部署来源。

Host 独立核验目标发布权限、真实远端稳定分支的认可状态、当前基线及其固定代码 SHA/后端完成依据，从该精确 SHA 建立干净构建快照，在唯一原型资产目录按指定模板冻结依赖、工程检查及静态构建，并执行纯静态浏览器冒烟；不复用任务 worktree 的未提交产物。内部构建快照不作为用户可切换的预览。发布记录关联 project/asset、基线 ID、固定代码 SHA、所含需求完成依据、构建标识和产物校验值；MD 内容 SHA-256、Git SHA 与部署产物校验值分开记录。只上传原型与合成 Mock，不把业务材料、凭证或内部路径上传到站点。

每项目只管理一个多页面原型工程和一个已配置 URL。页面和分享信息展示“项目当前演示”及当前成果标识，技术详情可查 SHA；Git 中交接资料仍固定，演示链接不表示历史交接时的页面快照。本地仅预览本人当前需求基础加自己的改动，不自动同步远程站点，用户无需选择本地或远端历史版本。

| 状态 | 进入条件 | 用户能看到什么 |
| --- | --- | --- |
| 已受理 | 记录发布操作，通过独立授权及当前已确认基线预核验 | 操作标识和阶段，不显示发布成功 |
| 构建中 | 干净快照检查、构建及静态冒烟 | 检查摘要及失败原因 |
| 部署中 | 持远端单站点锁，复核当前基线及其固定代码版本，临时上传、校验和原子替换 | 当前更新阶段，尚不确认可分享 |
| 验证中 | 当前站点已替换，操作仍持锁 | 实际内容标识、访问策略和关键交互检查 |
| 可分享 | 全部检查通过 | 唯一项目链接、二维码、访问方式/受众及当前成果标识 |
| 失败 | 必需步骤失败且结果已知 | 失败阶段、当前访问是否已撤回及修复重发入口，不显示已恢复旧站点 |
| 待确认 | 中断/取消/重启后远端结果未知 | 已知操作和查询入口，核对后继续，不假报成功或撤回 |

构建后先以纯静态服务器运行产物，检查路由、资源、Mock CRUD/空态/错误态及不向真实 API 透传；不得依赖开发服务器的服务端 Mock。构建和预验证失败不影响当前站点。

产物生成当前成果描述及文件校验清单，包含 asset ID、基线 ID、固定代码 SHA、构建和文件校验值；清单不计算自身，不写仓库 URL、原始需求材料或凭证。部署临时目录只用于本次上传校验，校验通过后在同一文件系统原子替换当前服务入口；目标 OS、权限、文件系统、Web 配置与操作语义必须 G0 验证。远端不维护历史发布目录、上一站点或可恢复旧产物。原子替换所需的临时旧文件仅属于部署操作的清理现场，不形成可选择/恢复版本；完成或故障收尾时清理并核验不可访问。

项目部署根下使用跨机器远端排他锁，覆盖上传、校验、原子替换、线上验证和必要撤回；可优先验证既有 OS 原语，不开发守护进程或发布平台。锁内重查项目当前基线及其固定代码 SHA、后端完成依据和稳定分支的认可状态、当前部署操作及产物标识；若请求基线已被新的已确认基线取代则停止该请求并基于当前基线重新构建，不能用旧请求覆盖站点。单纯后续 MD 阶段确认不更换部署基线。远端锁不替代需求占用或短暂集成窗口，也不阻断其他需求本地生产。等待及操作超时有上限，不以删除锁文件抢占活跃发布。

替换后从实际 URL 获取描述文件及关键 HTML/JS/CSS，和本次产物标识/校验值比对；浏览器执行关键模拟交互和已配置访问策略验证。受限站点须授权可读、未授权拒绝；显式公开站点验证公开访问符合预期。HTTPS 校验证书，HTTP 按项目配置验证；所选 Mock 模板的浏览器条件仍按 2.6 执行。不能只凭入口指向或页面版本文字宣布可分享。

浏览器缓存及采用 Service Worker 时的更新逻辑只用于刷新到当前站点。旧页面或资源不匹配时提示刷新当前页面，并验证重新加载后的产物一致；不建设多版本资源服务或旧版本回退，不承诺已经打开的页面在更新期间永不中断。

上传或替换前失败不改变当前站点；替换后验证失败则撤回当前访问并验证失效，修复并完成必要确认后重新构建、发布当前已确认基线，不切回旧站点。撤回需要明确授权并持同一远端锁。部分失败或撤回结果未知时显示待确认，不能宣布链接已关闭。失败现场可供诊断，但不得以历史站点对外访问。

SSH 中断、取消或宿主重启后，根据项目当前基线及其固定代码 SHA、后端认可状态、发布操作及远端当前入口/产物标识查询真实结果，再判断继续验证、撤回或重新发布；不凭本机状态重复替换。G0 验证远端进程和锁的存活/释放，不能假设桌面关闭即停止远端执行。部署维护者在既有设置落实临时文件清理、撤回权限和访问失效验证；不清理当前服务所需产物。记录可以保留审计历史，历史产物不提供恢复。服务器无法保证这些语义时修正单站点部署设计再实施，不另建多版本平台。
